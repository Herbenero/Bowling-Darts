Bowling Darts

First dart selects lane or hits Double for a Strike. Score remaining darts.

Rules
  • Dart 1: Selects lane (1–20). Double = Strike (X, value 10 + next 2 darts).
  • Dart 2: Double = Strike. Scoring: Outer=3, Middle=5, Inner=7, Triple=8, Quad=9.
  • Dart 3: If Dart 2+3 ≥ 10 = Spare (/, value 10 + next round's Dart 2).
  • Game advances only when End Turn is clicked.
